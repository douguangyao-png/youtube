- Parse input SRT with `srt.parse()` (lightweight SRT library, not pysubs2 — per research recommendation for DeepL pass)

- Batch translate via `deepl.Translator(auth_key).translate_text(texts, source_lang="EN", target_lang="ZH", split_sentences="nonewlines")` — single API call for all lines (anti-pattern: do NOT call per-line)

- Replace each subtitle's content with translated text
- Compose and write output SRT with `srt.compose(subtitles)`
- Log billed characters from `result.billed_characters` for usage monitoring (per user decision: monitor DeepL free tier usage)
- Return output_srt_path

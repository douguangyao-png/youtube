1. `build_bilingual_ass(en_srt_path: str, zh_srt_path: str, output_ass_path: str, video_height: int, is_vertical: bool) -> str`

Implementation per research Pattern 4:
- If both en_srt_path and zh_srt_path are empty strings, return "" (music video — skip subtitles)
- Create `pysubs2.SSAFile()`
- Define "Chinese" SSAStyle: fontname="Noto Sans CJK SC", fontsize=20 if vertical else 24, bold=True, primarycolor=Color(255,255,255,0), backcolor=Color(0,0,0,102), borderstyle=3, outline=0, shadow=0, alignment=2, wrap_style=0
  - CRITICAL: backcolor alpha=102 for 60% opacity (a=0 is opaque, a=255 is transparent in pysubs2 — per Pitfall 2 in research)
- Define "English" SSAStyle: same but fontsize=15 if vertical else 18, bold=False
- Calculate marginv: `int(video_height * (0.20 if is_vertical else 0.08))`
  - Chinese marginv = marginv + en_fontsize + 6 (above English line)
  - English marginv = marginv
- Load English SRT with `pysubs2.load(en_srt_path)` and Chinese SRT with `pysubs2.load(zh_srt_path)`
- For each pair of events (matched by index), create TWO SSAEvent entries in the output SSAFile:
  - Chinese event: style="Chinese", start/end from Chinese SRT segment
  - English event: style="English", start/end from English SRT segment
- Save to output_ass_path
- Return output_ass_path

Create `src/crosspost/transcoder.py` with two functions:

1. `probe_video(video_path: str) -> dict` — runs ffprobe via subprocess.run to extract video stream info (width, height, bit_rate, codec_name, r_frame_rate). Returns first stream dict from JSON output. Uses `capture_output=True, text=True, check=True`. Command per research Pattern 5.

2. `transcode_to_h264(input_path: str, output_path: str, source_bitrate_kbps: int) -> str` — transcodes to H.264 MP4. Key details:
   - CRF 20 if source_bitrate_kbps > 4000, else CRF 23 (per research)
   - Scale filter: only downscale to 1080p, never upscale. Use `scale=-2:'min(1080,ih)'` to avoid upscaling below-1080p sources (addresses Pitfall 6 from research)
   - `-c:a aac -b:a 128k` for audio
   - `-movflags +faststart` for web-compatible MP4
   - `subprocess.run(cmd, capture_output=True, check=True, timeout=600)`
   - `-y` flag to overwrite output
   - Returns output_path on success

Both functions use `from loguru import logger` for error logging. No retry decorator on these — retry is handled at the orchestrator level.

Create `tests/test_transcoder.py` with mocked subprocess tests for all behaviors listed above. Use `unittest.mock.patch("subprocess.run")` to mock ffprobe/ffmpeg calls.

  <action>
Create `src/crosspost/transcriber.py` with one main function:

`transcribe_to_srt(video_path: str, output_srt_path: str, model_size: str = "medium") -> str`

Implementation per research Pattern 6:
1. Create `WhisperModel(model_size, device="cpu", compute_type="int8")`
2. Call `model.transcribe(video_path, language="en", beam_size=5, vad_filter=True, vad_parameters={"threshold": 0.5})`
3. Consume generator: `segment_list = list(segments)`
4. If `not segment_list`: return `""` (pure music — NOT a failure, per user decision)
5. Convert to pysubs2 whisper format: `[{"start": s.start, "end": s.end, "text": s.text.strip()} for s in segment_list]`
6. Load via `pysubs2.load_from_whisper(whisper_segments)`
7. Save as SRT: `subs.save(output_srt_path, format_="srt")`
8. Return `output_srt_path`

IMPORTANT: Do NOT load the WhisperModel inside a retry loop (Pitfall from research — model loading is 2-10s). The model is loaded once per call. Retry at orchestrator level recreates only the transcribe call.

Create output directory with `Path(output_srt_path).parent.mkdir(parents=True, exist_ok=True)`.

Create `tests/test_transcriber.py` with mocked WhisperModel tests. Mock `faster_whisper.WhisperModel` to return fake segment objects. Test the music-video empty-segments path explicitly.

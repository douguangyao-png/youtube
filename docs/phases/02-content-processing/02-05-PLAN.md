Create `src/crosspost/processor.py` with:

1. `_process_single(content: Content, settings: AppSettings, engine: Engine) -> None`

Internal function implementing the full pipeline for one content item. Uses idempotent step pattern (research Pattern 1):

**Phase A: Parallel transcode + ASR (ThreadPoolExecutor, max_workers=2)**
- Check content.processed_video_path — skip transcode if already done
- Check content.srt_path — skip ASR if already done
- Submit both to ThreadPoolExecutor (research Pattern 2)
- Call `future.result()` on each to propagate exceptions (Pitfall 8)
- After both complete, write paths to Content row in a single session.commit()

**Phase B: Subtitle translation (sequential)**
- If srt_path is empty string (music video): skip translation and burn-in entirely
- Check content.translated_srt_path — skip if already done
- Call translate_srt
- Write translated_srt_path to Content row

**Phase C: Build ASS + burn subtitles (sequential)**
- If no subtitles (music video): skip
- Check content.ass_path — skip if already done
- Probe video for height, determine is_vertical (height > width)
- Call build_bilingual_ass
- Call burn_subtitles (produces final video with burned subs, replaces processed_video_path)
- Write ass_path and updated processed_video_path to Content row

**Phase D: Advance to PROCESSED**
- Set status=PROCESSED, processed_at=datetime.utcnow()
- session.commit()

**Phase E: Metadata translation**
- Check content.platform_metadata — skip if already done
- For each platform in ["toutiao", "baijiahao"]: call translate_metadata
- Store as JSON string: `json.dumps({"toutiao": {...}, "baijiahao": {...}})`
- Write platform_metadata, status=TRANSLATED, translated_at=datetime.utcnow()
- session.commit()

Wrap each phase in tenacity @retry(stop=stop_after_attempt(settings.processing.max_retries), wait=wait_exponential(multiplier=1, min=2, max=30)). On final failure, mark FAILED with error_message and return.

File naming convention for intermediate artifacts:
- Transcoded: `{output_dir}/{video_id}_transcoded.mp4`
- SRT: `{output_dir}/{video_id}_en.srt`
- Translated SRT: `{output_dir}/{video_id}_zh.srt`
- ASS: `{output_dir}/{video_id}_bilingual.ass`
- Final (burned): `{output_dir}/{video_id}_final.mp4`
